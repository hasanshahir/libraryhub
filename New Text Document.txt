Task Description
Objective
The objective of Week 2 (configured for a 8 weeks path) is to build a complete library management system with TypeScript, PostgreSQL and Prisma ORM, including roles, borrowing workflows, fines and reports.

Project Brief
Real-world problem: School and university libraries still track books and borrowers on registers, losing books and fines. LibraryHub digitises the catalogue, borrowing, returns and late fees.

Tech stack: TypeScript, Node.js + Express, PostgreSQL + Prisma ORM, React + TanStack Query, Tailwind CSS

This is a brand-new, standalone project. Create a new GitHub repository for it and deploy it live by the end of the week.

Practical Implementation
Project Task: LibraryHub — Library Management System

Must-Have Features

Librarians add books (title, author, ISBN, category, copies) and manage members.
Members search the catalogue by title/author/category and see availability.
Borrow and return flow with due dates; available copies update automatically.
Late returns generate fines; members see their history and pending fines.
Book reservation queue when all copies are borrowed.
Dashboard: most borrowed books, overdue list, total fines collected.
Bonus Features (for extra credit)

Barcode / ISBN lookup with Open Library API
Email reminders before due date
Acceptance Criteria (Definition of Done)

Borrowing is a transaction — copies can never go below zero.
Members cannot access librarian routes (403).
Prisma migrations committed; npm run seed creates realistic data.
Same Zod schemas validate on frontend and backend.
Deployed live with demo librarian and member accounts.
Day-by-Day Plan
Day 1: TypeScript basics for Node; set up Express + TS + Prisma; design schema and run migrations; seed data.
Day 2: Auth (register/login/logout) with JWT cookies; roles middleware; shared Zod schemas.
Day 3: Books & members APIs with search, filters and pagination.
Day 4: Borrow / return / reserve with prisma.$transaction; fines calculation.
Day 5: React + TanStack Query: catalogue, member area, librarian dashboard and reports.
Day 6: Testing edge cases, deploy, README with ERD, demo video.
